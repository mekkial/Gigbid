# Third-party component

`tessel-agent-landing.tsx` is the "Tessel Agent Landing" component by Kedhareswer Naidu (https://kedhar.pages.dev), used under the MIT licence
(https://kedhar-components.pages.dev/#tessel-agent-landing). The component file is the original with one change: the copy inside the four product-stage mock-ups (agent builder, connections, trace, approve-and-send) was rewritten to show GigBid's own agents, tools and measured numbers instead of generic support-desk examples (search the file for `GigBid:` and the `BuilderCard`, `ToolsCard`, `SPANS`, `DeployCard` blocks). Layout, animation and styling are untouched.
It depends on `gsap` (GreenSock standard licence, free for this use). Portraits embedded in the file are from Unsplash (Unsplash License); GigBid does not display them.
